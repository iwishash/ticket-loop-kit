# 루프 스펙 리포트

`bash scripts/ticket-loop.sh --parent <스펙>` 실행이 정상 종료하면(완료 · 더 처리할 티켓 없음 · 처리할 티켓 없음) 루프가 여기에 `spec-<N>.html` 한 장을 쓴다. 스펙의 하위 티켓마다 상태 · 작업 결과 브리프(PR 제목, 본문의 인수 조건 체크 수, 중단 사유, CI 소요 · 수리 횟수 · 병합 뒤 검증) · 경과 시간 · 사용 모델 · 마친 시각을 표로 담는다. 설명은 「Orca 티켓 무인 루프 가이드북」 7장 9단계, 이 저장소의 운영 문서는 `docs/agents/ticket-loop.md`.

- 같은 스펙은 같은 파일을 덮어쓴다 — 끝난 스펙의 리포트를 다시 뽑으려면 `bash scripts/ticket-loop.sh --parent <N>`을 한 번 더 돌린다(남은 티켓이 없으면 리포트만 만들고 끝난다)
- 루프는 커밋하지 않는다. 사람이 보고 PR로 올린다
- 경과 시간 · 모델의 원자료는 기계별 `.orca-loop/tickets.jsonl`(커밋 안 함)이다. 기록이 없는 티켓(다른 PC · 사람이 처리 · 이 기능 이전)은 PR 생성→병합 시간으로 대신하고 그렇게 표시하며 모델은 "미기록"으로 나온다
- 위치를 바꾸려면 `.orca-loop/loop.env`에 `REPORT_DIR`, `RECORDS_FILE`을 적는다
